# App screenshots

Place optimized portrait screenshots in this folder using these names:

- `login.webp`
- `home.webp`
- `plan-a-route.webp`
- `qr-code.webp`
- `outdoor-ar.webp`
- `indoor-ar.webp`
- `building-information.webp`
- `virtual-guide.webp`
- `arrival.webp`

The website automatically finds files with these names and replaces the matching labeled fallback panel. No component edit is required. Prefer WebP or AVIF, crop each image to the same portrait aspect ratio, and keep each file as small as practical.
