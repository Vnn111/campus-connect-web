# Campus Connect logo

Add the official logo to this folder using one of these filenames:

- `campus-connect-logo.svg`
- `campus-connect-logo.png`
- `campus-connect-logo.webp`
- `campus-connect-logo.avif`

The header, mobile menu, and footer will automatically use the file in place of the fallback location-pin mark. SVG is preferred when the official artwork is available.
